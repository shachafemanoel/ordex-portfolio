# רצף מבית OrdeX — הדגמה מודרכת

[פתיחת הדמו](https://ordex-demo-ju11d2.v2.appdeploy.ai/)

דף נחיתה, מסלול מודרך והתנסות חופשית לניהול הזמנות. זהו אתר סטטי עצמאי עם נתונים פיקטיביים בלבד, ללא הרשמה או חיבורים לשירותי העסק החיצוניים. ההמחשה האיזומטרית והמסך מציגים את אותה הזמנה ואת אותם תנאי יציאה.

## הרצה ובדיקות

נדרשים Node.js ‏22.12 ומעלה ו־npm. מריצים מתוך `demo-app`:

```sh
npm ci --ignore-scripts
npm run dev
npm run build
npm test
npm run e2e
```

בדיקות Playwright דורשות התקנת Chromium באמצעות `npx playwright install chromium`. המשתנה `DEMO_TEST_URL` מאפשר לכוון אותן לאתר שכבר רץ. דוח האימות מבחין בין בדיקות הלוגיקה, בדיקת הדפדפן שבוצעה בפועל והתרחישים האוטומטיים הכלולים בקוד.

## מה המבקר עושה

1. מתחיל במסלול המודרך עם DEMO-1001 ומעביר אותו לטיפול.
2. רואה שהמעבר למוכן חסום עד לסימון הכנת הפריטים.
3. קובע תאריך; מחסום היציאה נשאר סגור כל עוד חסר תשלום מלא.
4. מסמן תשלום בדמו, יוצא למשלוח ומשלים מסירה.
5. בודק היסטוריה ויוצר הזמנה פיקטיבית נוספת בהתנסות החופשית.

אפשר לדלג להדגמה החופשית, לחפש ולסנן, לבחור הזמנה, להשהות ולחדש טיפול או לבטל עם סיבה. התקנה היא מסלול חלופי, לא שלב חובה אחרי משלוח. פעולות החריגה נמצאות תחת „פעולות נוספות”.

## גבולות

- כל המצב בזיכרון הדפדפן; רענון ואיפוס מחזירים את שלוש הזמנות הדוגמה.
- התשלום הוא סימון בלבד. אין סליקה, קבלות, סנכרון חנות, הודעות, הרשאות שרת או חריגת מנהל בדמו.
- האירוח ב־AppDeploy מוסיף סרגל פלטפורמה ובקשות אירוח משלו; אין טענה שהדף המאוחסן מבצע אפס בקשות רשת חוצות־מקור.
- אין להזין פרטי לקוחות אמיתיים. נתוני כתובת וטלפון הם פיקטיביים ומתווספים אוטומטית.
- ניווט hash מאפשר לשתף קישורים ל־`#/guided` ול־`#/demo` בלי שרת ניתוב.
- ההמחשה היא SVG איזומטרי מהפרויקט הקיים, ולא מודל WebGL חדש. האנימציה מציגה מצב בלבד ואינה מבצעת פעולות בהזמנות.
- מדד „מוכנות ליציאה” סופר רק הזמנות במצב מוכן שעוברות את חסמי היציאה. אין חידוש סיור אוטומטי בעקבות חוסר פעילות.

## מקורות ותחזוקה

קוד הבסיס לדמו ולחוקי הזרימה הועתק מהדמו הציבורי בקומיט `c835a35`. רכיבי האיור, ערכת הציור ונכסי המותג מגיעים מ־OrdeX בקומיט `fd5a9a03ebdf7c6b481e8577a6c753ecad01bb45` ‏(PR #645). ה־MIT של ערכת Anatomy נשמר ב־`components/iso/LICENSE`.

`src/demo.ts` מנהל את הפעולות וההיסטוריה; `src/journey.ts` גוזר את ההדרכה, המוכנות ומצב ההמחשה מאותה הזמנה. מנוע ההמחשה מקבל מצב חיצוני בלבד, מכבד הפחתת תנועה ועוצר ציור כשהוא מחוץ למסך.

קובצי המקור האלה נפרסים לשורש אפליקציית AppDeploy הקיימת. בפריסה משתמשים ב־`appdeploy.package.json` כ־`package.json`: הוא מכיל את אותן תלויות אפליקציה ובנייה ללא כלי בדיקות Vitest ו־Playwright, שנותרים ב־`package.json` המקומי. תצורת Vitest נפרדת מתצורת Vite, כדי שהבנייה לא תהיה תלויה במתקין של כלי הבדיקות בענן. לא נפרסים קובצי הסביבה, שאר קוד המערכת, היסטוריית Git או קבצים מתיקיות אחרות. לפני עדכון יש לשמור גרסת פריסה אחרונה תקינה ולעיין במקור המרוחק. חזרה אפשרית באמצעות `apply_app_version` ב־AppDeploy.

הדמו המקורי ב־`../demo/index.html` ו־GitHub Pages נשמרו ללא שינוי.

ראו [אימות](docs/verification.md) ו־[בדיקת עיצוב](design-qa.md) לממצאים ולגבולות הבדיקה.
