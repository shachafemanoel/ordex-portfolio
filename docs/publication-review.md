# גבולות בדיקת הפרסום

החבילה נוצרה ב־3 בנובמבר 2026, בתיקייה נפרדת, לפי רשימת קבצים מפורשת.

- היסטוריית Git חדשה; ללא קומיטים, ענפים או tags מהפרויקט המקורי.
- לא הועתקו `.env`, גיבויים, dumps, CSV, לוגים, צילומי מערכת מקוריים, תיקיות AI, שיחות או symlinks.
- דמו עם שמות וכתובות המסומנים במפורש כדוגמאות וטלפון לא תקין במכוון (`0000000000`). אין כתובות אימייל או פרטי חיבור ללקוחות.
- חוקי הליבה נבדקו בבדיקות הרגרסיה שנבחרו ובבדיקות שילוב של הדמו. לא נטען שכל בדיקות המערכת המקורית עוברות.
- סריקת Gitleaks לתכולת החילוץ והיסטוריית Git החדשה נועדה לזהות סודות מוכרים. סריקה נקייה אינה הוכחה להעדר כל סוג מידע רגיש.
- `npm audit` נבדק בזמן ההכנה; המצב עשוי להשתנות עם פרסום חולשות חדשות.
- בדיקות הדפדפן המקומיות רצות ב־Chromium. אין טענה לבדיקה מלאה בכל הדפדפנים או לעמידה מלאה בתקן נגישות.
- לא הוקמו שירותי ענן, מסד נתונים, שירותי תשלום או חנות. אין כאן טענה לפריסת אתר חי.

תוצאות מקומיות: TypeScript ובניית production עברו; 40 בדיקות לוגיקה ו־5 בדיקות Chromium עברו. Gitleaks לתיקיית החילוץ: 0 ממצאים. npm audit: 0 חולשות מדווחות.
